# [JEUNIT](https://djoezeke.github.io/jeunit) [ EXAMPLES ]

This folder contains code examples for the C and C++ APIs.

> [!NOTE]
> Jeunit is still in development, **current version is incomplete and nonfunctional**.
> There is more room for improvements.

The purpose of Examples is to showcase integration, let you try Jeunit, and guide you toward
integrating Jeunit in your own application.

## Getting Started

Integration in a typical existing application, should take no time.

```cpp
#include <jeunit/jeunit.h>
```

Main resource:

- Read **[Documentation](https://djoezeke.github.io/jeunit/)** for detailed on how to integrate Jeunit.
